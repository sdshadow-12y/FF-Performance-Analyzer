# FF Performance Analyzer

A starter Android Studio project for manually analyzing Free Fire gameplay performance.

## Features
- Manual match-stat input: kills, deaths, damage, headshot percentage, survival time
- K/D and damage-per-kill calculation
- Rule-based performance notes and practice suggestions
- Dark professional esports-inspired dashboard

## Important limitations
- This starter does not connect to Free Fire servers, access game files, record gameplay, or fetch player data by UID.
- The analysis is rule-based, not a trained AI model. It is designed as an offline prototype.
- Enter your own match statistics. Do not share account passwords or login codes with third-party tools.

## Build
1. Open this folder in Android Studio.
2. Allow Gradle sync to finish.
3. Connect an Android phone with USB debugging enabled, or use an emulator.
4. Press Run.

To create an APK: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
